\begin{abstract}
This report presents experimental results from testing email authentication edge cases across multiple mail providers. We evaluate SPF, DKIM, DMARC, and ARC handling under various misconfigurations and attack scenarios. Results reveal inconsistent enforcement and potential spoofing vectors.
\end{abstract}

%==============================================================================
\section{Introduction}
%==============================================================================

Email authentication relies on SPF, DKIM, and DMARC to prevent sender spoofing. Despite standardization (RFC 7208, RFC 6376, RFC 7489), provider implementations vary significantly. Prior work~\cite{hu2018endtoend,chen2020composition,shen2021weaklinks} demonstrated that spoofing remains possible through protocol edge cases and UI inconsistencies.

This study tests \textbf{25 attack scenarios} against 14 receiving providers:
\begin{itemize}[noitemsep]
    \item Gmail, iCloud, Yahoo, Outlook, AOL
    \item ProtonMail, Fastmail, Tutamail, Zoho
    \item GMX, Mail.ru, Laposte, Mail.com
    \item Grenoble INP Mail
\end{itemize}

\noindent\textbf{Goals:}
\begin{enumerate}[noitemsep]
    \item Document provider-specific authentication behaviors
    \item Identify exploitable misconfigurations
    \item Compare results with prior academic findings
\end{enumerate}
